4. Suveræn Gældsmatematik: WAM-Rollover (5,9 år), Term Premium & Knækpunkter

Pengepolitikkens reelle lag-effekt på balancesiden er 5–6 år (Weighted Average Maturity), ikke 12–18 måneder.

(1) it+1w = [ (1 − α)Dt·itw + (αDt + PDt + IEt)·itm ] / Dt+1   |   (2) Δbt = (rtw − gt)bt + pdt   |   (3) Dt / Pt = ∑ Et[st+j] / (1 + r)j
Parametre (USA, Nov 2026): D0 = $32,43T (Brutto: $40,58T) • WAM = 71 mdr. (5,9 år) • α = 0,33 ($10,7T rollover/12 mdr.) • i0w = 3,531 % • im = 4,80–5,20 % (inkl. Term Premium).
Fremskrivning (IEt = itw · Dt): 2026: $1,05T (3,6 % BNP) → 2027: $1,45T (4,8 %) → 2028: $1,73T (5,6 %) → 2030: $2,14T+ (6,7 %+ BNP).
